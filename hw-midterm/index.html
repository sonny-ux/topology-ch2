The Set Toolkit

Most proofs in point-set topology consist of unwinding definitions and then applying a set-theoretic identity. This tab collects the identities and proof patterns that the homework uses repeatedly.

01 Proving Two Sets Are Equal

Main Idea
Two sets are equal exactly when each is contained in the other. To prove $S=T$, you prove $S\subset T$ and $T\subset S$ as two separate arguments. Each argument starts with an arbitrary element of one set and shows that it belongs to the other.

Many problems do not look like set-equality problems but are: "the two topologies are the same" (HW1 Q3b, HW1 Q4), "this set equals the image $f(X)$" (HW3 Q4a), "the closure of a finite union is the union of the closures" (HW2 Q5b). A topology is itself a set (a set of subsets), so proving that two topologies are equal is also a two-inclusion argument: every set open in the first topology is open in the second, and conversely.

Recall the notation. In Munkres, $A\subset B$ means every element of $A$ is an element of $B$. It does not mean proper subset, so $A\subset A$ is true.

Template — two inclusions

($\subset$) Let $x\in S$. [Unwind what $x\in S$ means.] … Therefore $x\in T$.

($\supset$) Let $x\in T$. [Unwind what $x\in T$ means.] … Therefore $x\in S$.

Since $S\subset T$ and $T\subset S$, $S=T$.

Worked example

Claim. For any sets $A,B,C$: $A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$.

($\subset$) Let $x\in A\cap(B\cup C)$. Then $x\in A$, and $x\in B$ or $x\in C$. If $x\in B$, then $x\in A\cap B$. If $x\in C$, then $x\in A\cap C$. Either way $x\in(A\cap B)\cup(A\cap C)$.

($\supset$) Let $x\in(A\cap B)\cup(A\cap C)$. If $x\in A\cap B$, then $x\in A$ and $x\in B\subset B\cup C$. If $x\in A\cap C$, then $x\in A$ and $x\in C\subset B\cup C$. Either way $x\in A\cap(B\cup C)$.

This identity, intersection distributing over union, is the step that does the work in HW1 Q4. There the subspace topology of $A$ inside $Y$ produces sets of the form $A\cap(Y\cap U)$, and you need to simplify them.

Common mistake
Proving only one inclusion and writing "similarly" for the other. The two directions often use different facts. In HW3 Q4a, one direction uses $g\circ f=\mathrm{id}_X$ and the other uses the definition of image. Write both directions out.

02 Images and Preimages

Main Idea
Given a function $f:X\to Y$, the image of a set pushes it forward into $Y$, and the preimage of a set pulls it back into $X$. Preimages preserve every set operation. Images preserve unions only. This is why continuity is defined with preimages.

Continuity in topology is defined by preimages: $f$ is continuous when the preimage of every open set is open. Every continuity proof therefore uses the preimage identities below. Images appear when a problem asks whether a map sends open sets to open sets (HW2 Q2) or asks you to describe $f(X)$ (HW3 Q4).

Definitions

For $A\subset X$: $\;f(A)=\{f(a)\mid a\in A\}\subset Y$.

For $B\subset Y$: $\;f^{-1}(B)=\{x\in X\mid f(x)\in B\}\subset X$.

Reading the definitions

$y\in f(A)$ means: there exists some $a\in A$ with $f(a)=y$. So to use the statement $y\in f(A)$ in a proof, write "choose $a\in A$ with $f(a)=y$."

$x\in f^{-1}(B)$ means only that $f(x)\in B$. No existence claim is involved, and $f$ need not be invertible. The notation $f^{-1}(B)$ makes sense for every function.

Preimage identities §2

$f^{-1}\big(\bigcup_\alpha B_\alpha\big)=\bigcup_\alpha f^{-1}(B_\alpha)$, $\quad f^{-1}\big(\bigcap_\alpha B_\alpha\big)=\bigcap_\alpha f^{-1}(B_\alpha)$, $\quad f^{-1}(Y\setminus B)=X\setminus f^{-1}(B)$.

Images: $f\big(\bigcup_\alpha A_\alpha\big)=\bigcup_\alpha f(A_\alpha)$, but only $f(A_1\cap A_2)\subset f(A_1)\cap f(A_2)$, with equality when $f$ is injective.

Round trips: $f(f^{-1}(B))\subset B$ (equal to $B\cap f(X)$), and $A\subset f^{-1}(f(A))$ (equal when $f$ is injective).

Worked example — image of an intersection

Let $f:\mathbb{R}\to\mathbb{R}$, $f(x)=x^2$, $A_1=[-2,-1]$, $A_2=[1,2]$. Then $A_1\cap A_2=\varnothing$, so $f(A_1\cap A_2)=\varnothing$. But $f(A_1)=f(A_2)=[1,4]$, so $f(A_1)\cap f(A_2)=[1,4]\neq\varnothing$. The inclusion is strict because $f$ is not injective: $-1$ and $1$ have the same image.

Worked example — preimage of a complement

Claim. $f^{-1}(Y\setminus B)=X\setminus f^{-1}(B)$.

$x\in f^{-1}(Y\setminus B)\iff f(x)\in Y\setminus B\iff f(x)\notin B\iff x\notin f^{-1}(B)\iff x\in X\setminus f^{-1}(B)$.

Each step is a definition, so a chain of "if and only if" statements proves both inclusions at once. This identity is why "preimages of open sets are open" is equivalent to "preimages of closed sets are closed." The midterm cofinite problem (MT Q4) uses it.

Worked example — preimage of a finite set under an injection

If $f:X\to Y$ is injective and $F\subset Y$ is finite with $n$ elements, then $f^{-1}(F)$ has at most $n$ elements. Reason: each $y\in F$ has at most one preimage (injectivity), and $f^{-1}(F)=\bigcup_{y\in F}f^{-1}(\{y\})$ is a union of $n$ sets, each with at most one element. Without injectivity this fails: for the constant function $f\equiv 0$ on $\mathbb{R}$, $f^{-1}(\{0\})=\mathbb{R}$.

03 Indexed Unions, Intersections, and De Morgan's Laws

Main Idea
An indexed family $\{A_j\}_{j\in J}$ assigns a set $A_j$ to each element $j$ of an index set $J$, which may be infinite or even uncountable. The union $\bigcup_{j\in J} A_j$ contains the points that lie in at least one $A_j$. The intersection $\bigcap_{j\in J}A_j$ contains the points that lie in every $A_j$.

Topology depends on the difference between "arbitrary" and "finite." Open sets are closed under arbitrary unions but only finite intersections. Correspondingly, closed sets are closed under arbitrary intersections but only finite unions. De Morgan's laws convert one statement into the other. HW2 Q5 depends on exactly this finite-versus-arbitrary difference.

De Morgan's laws
$X\setminus\bigcup_{j}A_j=\bigcap_j(X\setminus A_j)\qquad X\setminus\bigcap_jA_j=\bigcup_j(X\setminus A_j)$
Reading the formula
A point is outside the union exactly when it is outside every $A_j$. A point is outside the intersection exactly when it is outside at least one $A_j$. Taking complements turns "for all" into "there exists" and the reverse.
Worked example — an infinite intersection of open sets need not be open

In $\mathbb{R}$, let $U_n=(-1/n,1/n)$ for $n=1,2,3,\dots$. Each $U_n$ is open. Their intersection is $\{0\}$: the point $0$ lies in every $U_n$, and any $x\neq0$ fails to lie in $U_n$ once $1/n\lt|x|$. The set $\{0\}$ is not open in $\mathbb{R}$. Taking complements gives the closed-set version: the sets $\mathbb{R}\setminus U_n$ are closed, but their union $\mathbb{R}\setminus\{0\}$ is not closed.

A similar example with closures settles HW2 Q5c: let infinitely many closed sets accumulate at a point that none of them contains.

Worked example — complement of a product

For sets $A\subset X$ and $B\subset Y$: $\;(X\times Y)\setminus(A\times B)=\big((X\setminus A)\times Y\big)\cup\big(X\times(Y\setminus B)\big)$.

Reason: $(x,y)\notin A\times B$ means it is false that both $x\in A$ and $y\in B$. So $x\notin A$ or $y\notin B$, and those are the two pieces of the union. For an arbitrary product, the same reasoning gives $\prod X_j\setminus\prod A_j=\bigcup_k\pi_k^{-1}(X_k\setminus A_k)$. This identity is the key step in MT Q5.

04 Quantifiers, Negations, and Counterexamples

Main Idea
To prove that something fails (a collection is not a topology, a set is not open, a function is not continuous), negate the definition carefully. The negation of "for every $x$, P" is "there exists $x$ for which P fails." So you need one explicit witness.

Several problems ask you to show that something does not hold: HW1 Q1 (an axiom fails), MT Q1b ($\{0\}$ is not open in $\mathbb{Q}$), HW3 Q6 ($m$ is not continuous). In each case the proof consists of finding the witness and checking that it works.

Common negations

$U$ is open in the topology generated by a basis $\mathcal{B}$: for every $x\in U$ there exists $B\in\mathcal{B}$ with $x\in B\subset U$.
Negation: there exists $x\in U$ such that every $B\in\mathcal{B}$ containing $x$ fails to lie inside $U$.

$f$ is continuous: for every open $V$, $f^{-1}(V)$ is open.
Negation: there exists an open $V$ with $f^{-1}(V)$ not open.

$\mathcal{T}$ is closed under unions: for every subcollection, the union lies in $\mathcal{T}$.
Negation: there exist specific sets in $\mathcal{T}$ whose union is not in $\mathcal{T}$.

Worked example

Claim. $[0,1)$ is not open in $\mathbb{R}$ (standard topology, with basis the open intervals).

The witness point is $x=0$. Any basis element containing $0$ is an interval $(a,b)$ with $a\lt0\lt b$. It contains the point $a/2$, which is negative and so not in $[0,1)$. Hence no basis element around $0$ lies inside $[0,1)$, and $[0,1)$ is not open.

Topologies and Bases

What a topology is, how to check the axioms, and how a basis lets you describe a topology without listing every open set.

01 The Axioms for a Topology

Main Idea
In Modern Analysis, open sets were defined from a distance: $U$ is open if every point has a small ball around it inside $U$. Topology keeps only three properties that open sets have and takes those properties as the definition. A topology on a set is simply a choice of which subsets count as "open," subject to three rules.

This abstraction lets the same theorems apply to $\mathbb{R}$, to finite sets, and to infinite products, where no natural distance may exist. On a small finite set you can list every open set and check the axioms directly. HW1 Q1 and the midterm finite-space problems ask for exactly this.

Definition — topology §12
A topology on a set $X$ is a collection $\mathcal{T}$ of subsets of $X$ such that:
  1. $\varnothing$ and $X$ are in $\mathcal{T}$.
  2. The union of the elements of any subcollection of $\mathcal{T}$ is in $\mathcal{T}$.
  3. The intersection of the elements of any finite subcollection of $\mathcal{T}$ is in $\mathcal{T}$.
The pair $(X,\mathcal{T})$ is a topological space, and the members of $\mathcal{T}$ are the open sets.
Reading the definition
$\mathcal{T}$ is a set whose elements are themselves subsets of $X$. So $\mathcal{T}\subset\mathcal{P}(X)$, where $\mathcal{P}(X)$ denotes the power set, the set of all subsets of $X$. Axiom (2) allows unions of any size, including infinite ones. Axiom (3) requires closure only under finite intersections. For a finite collection, it suffices to check that the intersection of any two members is a member, because a longer finite intersection can be built up two sets at a time. When $X$ is finite, $\mathcal{T}$ is finite too, so axiom (2) also reduces to checking that the union of any two members is a member.
Standard examples §12
  • Discrete topology: $\mathcal{T}=\mathcal{P}(X)$. Every subset is open.
  • Indiscrete (trivial) topology: $\mathcal{T}=\{\varnothing,X\}$. Only the two required sets are open.
  • Finite complement topology $\mathcal{T}_f$: $U$ is open if $U=\varnothing$ or $X\setminus U$ is finite. On an infinite set, nonempty open sets are therefore very large.
  • Standard topology on $\mathbb{R}$: generated by the open intervals (see Section 03).
Worked example — checking the axioms on a small set

Let $X=\{1,2,3\}$ and $\mathcal{S}=\{\varnothing,\{1\},\{2\},X\}$. Is $\mathcal{S}$ a topology?

Axiom (1): $\varnothing\in\mathcal{S}$ and $X\in\mathcal{S}$. Satisfied.

Axiom (2): check the union of each pair. $\{1\}\cup\{2\}=\{1,2\}$, which is not in $\mathcal{S}$. The axiom fails, and this pair is the witness.

Axiom (3): check the intersection of each pair. $\{1\}\cap\{2\}=\varnothing\in\mathcal{S}$. Every intersection involving $\varnothing$ is $\varnothing$, and every intersection with $X$ returns the other set. Satisfied.

So $\mathcal{S}$ satisfies (1) and (3) but not (2), and it is not a topology. When a problem asks about each axiom separately, as HW1 Q1 does, answer each one with either a witness for failure or a complete check.

Common mistakes

For axiom (3), the "empty intersection" is a convention issue. Munkres means intersections of nonempty finite subcollections, so do not worry about it.

Do not confuse "an element of $\mathcal{T}$" with "an element of $X$." $\{b\}\in\mathcal{T}$ says the subset $\{b\}$ is open. $b\in X$ says $b$ is a point.

02 Finer and Coarser Topologies

Main Idea
A single set can carry many topologies. Two topologies on the same set are compared by inclusion: the one with more open sets is finer. The discrete topology is the finest possible and the indiscrete topology is the coarsest.

This comparison is the subject of HW3 Q2, which shows that "$\mathcal{T}$ is finer than $\mathcal{T}'$" is equivalent to "the identity map from $(X,\mathcal{T})$ to $(X,\mathcal{T}')$ is continuous." It is also the language of HW1 Q3b, where you show two topologies on $\mathbb{R}$ are equal by showing each is finer than the other.

Definition §12
If $\mathcal{T}\subset\mathcal{T}'$, then $\mathcal{T}'$ is finer than $\mathcal{T}$, and $\mathcal{T}$ is coarser than $\mathcal{T}'$. Munkres adds "strictly" when the inclusion is proper. Two topologies are comparable if one contains the other.
Worked example

On $X=\{a,b\}$, the four topologies are $\{\varnothing,X\}$, $\{\varnothing,\{a\},X\}$, $\{\varnothing,\{b\},X\}$, and $\mathcal{P}(X)$. The middle two are not comparable: neither contains the other. Both are finer than the indiscrete topology and coarser than the discrete one.

03 Basis for a Topology

Main Idea
Listing every open set is usually impossible. A basis is a smaller collection of "building blocks" from which every open set is formed. In $\mathbb{R}$, the open intervals form a basis: a set is open when every point lies in some open interval contained in the set. This is the familiar analysis definition.

A basis has to satisfy two conditions so that the open sets it generates actually form a topology. The first ensures the whole space is covered. The second ensures that the intersection of two building blocks can itself be built from blocks, which is what makes axiom (3) hold.

Definition — basis §13
A basis for a topology on $X$ is a collection $\mathcal{B}$ of subsets of $X$ (the basis elements) such that:
  1. For each $x\in X$, there is at least one $B\in\mathcal{B}$ with $x\in B$.
  2. If $x\in B_1\cap B_2$ with $B_1,B_2\in\mathcal{B}$, then there is $B_3\in\mathcal{B}$ with $x\in B_3\subset B_1\cap B_2$.
The topology generated by $\mathcal{B}$: $U\subset X$ is open if for each $x\in U$ there is $B\in\mathcal{B}$ with $x\in B\subset U$.
Reading the definition

Condition (2) does not require $B_1\cap B_2$ itself to be a basis element. It requires only that around each point of the intersection there is a smaller basis element still inside the intersection. In $\mathbb{R}$, the intersection of two open intervals is an open interval or empty, so (2) holds with $B_3=B_1\cap B_2$. For open discs in the plane, the intersection of two discs is a lens shape, not a disc, but a small disc fits around each point of the lens.

The generating rule "for each $x\in U$ there is $B$ with $x\in B\subset U$" has the same form as "for each $x\in U$ there is $\varepsilon\gt0$ with $(x-\varepsilon,x+\varepsilon)\subset U$." The basis element plays the role of the $\varepsilon$-interval.

Lemma 13.1 §13
The topology generated by $\mathcal{B}$ equals the collection of all unions of elements of $\mathcal{B}$.
Why this matters
This gives a second description of the open sets, and it is often easier to use: an open set is a union of basis elements. On a finite set, you compute the generated topology by forming every possible union of basis elements and adding $\varnothing$, which is the empty union.
Worked example — checking basis axioms on a small set

Let $X=\{1,2,3\}$ and $\mathcal{C}=\{\{1,2\},\{2,3\}\}$.

Condition (1): $1\in\{1,2\}$, $2\in\{1,2\}$, $3\in\{2,3\}$. Every point is covered. Satisfied.

Condition (2): the only intersection of two different elements is $\{1,2\}\cap\{2,3\}=\{2\}$, containing the point $2$. We need some $B_3\in\mathcal{C}$ with $2\in B_3\subset\{2\}$, so $B_3$ must be $\{2\}$, which is not in $\mathcal{C}$. Condition (2) fails, with witness $x=2$, $B_1=\{1,2\}$, $B_2=\{2,3\}$.

Adding $\{2\}$ repairs it. $\mathcal{C}'=\{\{2\},\{1,2\},\{2,3\}\}$ satisfies both conditions, and by Lemma 13.1 it generates $\{\varnothing,\{2\},\{1,2\},\{2,3\},X\}$.

The intersections of an element with itself, such as $B_1=B_2=\{1,2\}$, always satisfy (2) by taking $B_3=B_1$, so you only need to check pairs of different elements.

Common mistake
A collection can be a basis without being a topology. For example, $\mathcal{C}'$ above lacks $\varnothing$ and $X$. A basis need not satisfy the topology axioms. It only needs to generate a topology. HW1 Q1 and Q2 use the same collection specifically to make you notice this.

04 Comparing Topologies via Bases

Main Idea
To show one topology is finer than another, you do not need to check every open set. It is enough to check basis elements: every basis element of the coarser topology must be "fillable," around each of its points, by a basis element of the finer one.

This reduces "these two topologies on $\mathbb{R}$ are equal" to a concrete statement about intervals. HW1 Q3b is an instance: the rational-endpoint intervals generate the same topology as all open intervals.

Lemma 13.3 §13
Let $\mathcal{B}$ and $\mathcal{B}'$ be bases for topologies $\mathcal{T}$ and $\mathcal{T}'$ on $X$. The following are equivalent:
  1. $\mathcal{T}'$ is finer than $\mathcal{T}$.
  2. For each $x\in X$ and each $B\in\mathcal{B}$ containing $x$, there is $B'\in\mathcal{B}'$ with $x\in B'\subset B$.
Reading the lemma
The primed basis elements must fit inside the unprimed ones, around every point. Finer means smaller building blocks are available. To show $\mathcal{T}=\mathcal{T}'$, apply the lemma twice, once in each direction.
Lemma 13.2 — recognizing a basis §13
Let $(X,\mathcal{T})$ be a topological space and $\mathcal{C}\subset\mathcal{T}$ a collection of open sets such that for each open $U$ and each $x\in U$ there is $C\in\mathcal{C}$ with $x\in C\subset U$. Then $\mathcal{C}$ is a basis, and it generates $\mathcal{T}$.
Worked example — the lower limit topology is finer than the standard one

Let $\mathcal{B}$ be the open intervals $(a,b)$, generating the standard topology $\mathcal{T}$. Let $\mathcal{B}'$ be the half-open intervals $[a,b)$, generating the lower limit topology $\mathcal{T}_\ell$ (§13).

$\mathcal{T}_\ell$ is finer than $\mathcal{T}$. Take $x\in(a,b)$. Then $[x,b)$ is a basis element of $\mathcal{B}'$ with $x\in[x,b)\subset(a,b)$. By Lemma 13.3, $\mathcal{T}\subset\mathcal{T}_\ell$.

$\mathcal{T}$ is not finer than $\mathcal{T}_\ell$. Take $x=0$ and $B'=[0,1)$. Every open interval containing $0$ contains negative numbers, so none lies inside $[0,1)$. The condition of Lemma 13.3 fails at this witness.

For HW1 Q3b the structure is the same, but both directions succeed. In one direction a rational-endpoint interval is already an open interval. In the other, you use the density of $\mathbb{Q}$ to find rationals $q_1,q_2$ with $a\lt q_1\lt x\lt q_2\lt b$.

Fact you may use — density of $\mathbb{Q}$
Between any two real numbers $a\lt b$ there is a rational number $q$ with $a\lt q\lt b$. This is from your analysis prerequisites (the Archimedean property), so it can be used without proof.

The Subspace Topology

How a subset inherits a topology, how "open in $Y$" differs from "open in $X$," and how to compute $\mathcal{T}_A$ on a finite set.

01 Definition

Main Idea
Any subset $Y$ of a topological space becomes a topological space in its own right: its open sets are the traces that open sets of $X$ leave on $Y$. You "look at $X$ through the window $Y$."

This is how $[0,1]$, $\mathbb{Q}$, and $\mathbb{Z}$ get their topologies from $\mathbb{R}$. Whenever a problem says "$A\subset X$ with the subspace topology" or "regard $A$ as a subspace," this is the topology meant. MT Q1a asks you to state the definition word for word.

Definition — subspace topology §16
Let $(X,\mathcal{T})$ be a topological space and $Y\subset X$. The subspace topology on $Y$ is $$\mathcal{T}_Y=\{\,Y\cap U\mid U\in\mathcal{T}\,\}.$$ With this topology, $Y$ is called a subspace of $X$.
Reading the formula
Each open set $U$ of $X$ contributes one open set $Y\cap U$ of $Y$, namely the part of $U$ inside $Y$. Different $U$'s can contribute the same trace, so $\mathcal{T}_Y$ may have fewer elements than $\mathcal{T}$. Munkres checks in §16 that $\mathcal{T}_Y$ satisfies the three axioms, using $Y\cap\bigcup U_\alpha=\bigcup(Y\cap U_\alpha)$ and $(Y\cap U_1)\cap(Y\cap U_2)=Y\cap(U_1\cap U_2)$.
Lemma 16.1 — basis for a subspace §16
If $\mathcal{B}$ is a basis for the topology of $X$, then $\{\,B\cap Y\mid B\in\mathcal{B}\,\}$ is a basis for the subspace topology on $Y$.
Worked example — $\mathbb{Z}$ is discrete as a subspace of $\mathbb{R}$

For $n\in\mathbb{Z}$: $\{n\}=\mathbb{Z}\cap(n-\tfrac12,n+\tfrac12)$, and $(n-\tfrac12,n+\tfrac12)$ is open in $\mathbb{R}$. So every one-point set is open in $\mathbb{Z}$. Since every subset of $\mathbb{Z}$ is a union of one-point sets, every subset is open, and the subspace topology on $\mathbb{Z}$ is discrete.

Contrast with $\mathbb{Q}$ (MT Q1b). In $\mathbb{Q}$ the one-point set $\{0\}$ is not open. If $\{0\}=\mathbb{Q}\cap U$ for some open $U\subset\mathbb{R}$, then $U$ contains $0$ and hence an interval $(-\varepsilon,\varepsilon)$, and that interval contains a nonzero rational. The density of $\mathbb{Q}$ is what prevents isolating a point.

02 Open in $Y$ versus Open in $X$

Main Idea
"Open" always means open in some particular space. A set can be open in the subspace $Y$ without being open in $X$. For example, $(\tfrac12,1]$ is open in $[-1,1]$ but not in $\mathbb{R}$. The extra points outside $Y$ that would have been required are simply absent from $Y$.

HW1 Q5 is entirely about this distinction, using $Y=[-1,1]\subset\mathbb{R}$. A useful picture: inside $Y=[-1,1]$, an endpoint such as $1$ has no points to its right, so a set like $(\tfrac12,1]$ already contains a whole "neighborhood" of $1$ as seen from within $Y$.

Lemma 16.2 §16
Let $Y$ be a subspace of $X$. If $U$ is open in $Y$ and $Y$ is open in $X$, then $U$ is open in $X$.
Reading the lemma
$U$ open in $Y$ means $U=Y\cap V$ with $V$ open in $X$. If $Y$ is also open in $X$, then $Y\cap V$ is an intersection of two open sets of $X$, so it is open in $X$. When $Y$ is not open, as with $Y=[-1,1]$, the lemma does not apply and the conclusion can fail.
Worked example — deciding both questions

Take $Y=[0,2]\subset\mathbb{R}$.

$S=(1,2]$. Open in $\mathbb{R}$? No: no open interval around $2$ fits inside $S$. Open in $Y$? Yes: $S=Y\cap(1,3)$.

$T=(1,3]$. Not a subset of $Y$, so the question "open in $Y$" does not apply. Open in $\mathbb{R}$? No, because of the endpoint $3$.

$W=(\tfrac12,1)$. Open in $\mathbb{R}$, since it is an open interval. Open in $Y$: yes, $W=Y\cap W$. In general, a subset of $Y$ that is open in $X$ is always open in $Y$.

Procedure. (i) Is the set a subset of $Y$? (ii) For open in $\mathbb{R}$: does every point have an open interval around it inside the set? (iii) For open in $Y$: can you write it as $Y\cap U$ with $U$ open in $\mathbb{R}$? The points that matter are the endpoints of $Y$.

Watch the set-builder notation
In HW1 Q5, sets (a)–(c) are defined with $x\in\mathbb{R}$, but (d) and (e) are defined with $x\in Y$. The condition "$\tfrac12\lt|x|\lt2$" restricted to $x\in Y$ describes a different set from the same condition with $x\in\mathbb{R}$. Write each set out as a union of intervals before answering.

03 Computing $\mathcal{T}_A$ on a Finite Set

Main Idea
On a finite space, compute $\mathcal{T}_A$ by intersecting $A$ with each open set of $X$, one at a time, and then deleting repeats. The number of distinct traces can be smaller than $|\mathcal{T}|$, because different open sets can have the same intersection with $A$.

This is a mechanical computation, but exams grade both the set notation and the explanation of the count. HW1 Q6b specifically asks why the count is what it is. The answer is always to name the two open sets of $X$ that give the same trace.

Worked example

Let $X=\{p,q,r,s\}$ with $\mathcal{T}=\{\varnothing,\{p\},\{p,q\},\{p,r\},\{p,q,r\},X\}$, and let $A=\{q,r,s\}$.

Intersect $A$ with each open set:

  • $A\cap\varnothing=\varnothing$
  • $A\cap\{p\}=\varnothing$
  • $A\cap\{p,q\}=\{q\}$
  • $A\cap\{p,r\}=\{r\}$
  • $A\cap\{p,q,r\}=\{q,r\}$
  • $A\cap X=\{q,r,s\}$

So $\mathcal{T}_A=\{\varnothing,\{q\},\{r\},\{q,r\},\{q,r,s\}\}$, which has 5 elements, not 6. Justification of the count: the two distinct open sets $\varnothing$ and $\{p\}$ have the same trace $\varnothing$ on $A$, because $p\notin A$. The remaining four traces are pairwise different, as the list shows.

Notation is graded
Write $\mathcal{T}_A=\{\varnothing,\{q\},\dots\}$. This is a set of sets, so it has outer braces enclosing inner braces. Writing $\{q\}$ when you mean the point $q$, or the reverse, loses credit. $\varnothing$ is an element of $\mathcal{T}_A$. It is not the same thing as $\{\varnothing\}$.

Closed Sets, Closure, and Hausdorff Spaces

Closed sets, interior and closure, the neighborhood test for closure, closure inside a subspace, convergence of sequences, and the Hausdorff condition.

01 Closed Sets

Main Idea
A set is closed when its complement is open. Closed is not the opposite of open. A set can be both, as $\varnothing$ and $X$ always are, or neither, as $[0,1)$ is in $\mathbb{R}$.

Closed sets are needed to define closure, and closure is needed for density, which HW3 Q3 uses. Many problems are also easier to state with closed sets. In a finite space, list the closed sets first: take the complement of each open set.

Definition §17
$A\subset X$ is closed if $X\setminus A$ is open.
Theorem 17.1 §17
$\varnothing$ and $X$ are closed. Arbitrary intersections of closed sets are closed. Finite unions of closed sets are closed.
Why
Take complements of the three topology axioms and apply De Morgan's laws. An arbitrary union of open sets becomes an arbitrary intersection of closed sets. A finite intersection becomes a finite union.
Theorem 17.2 — closed sets in a subspace §17
Let $Y$ be a subspace of $X$. A set $A\subset Y$ is closed in $Y$ if and only if $A=C\cap Y$ for some $C$ closed in $X$.
Worked example

With $X=\{p,q,r,s\}$ and $\mathcal{T}=\{\varnothing,\{p\},\{p,q\},\{p,r\},\{p,q,r\},X\}$ (the example from the Subspaces tab), the closed sets are the complements:

$X,\ \{q,r,s\},\ \{r,s\},\ \{q,s\},\ \{s\},\ \varnothing.$

Every nonempty closed set contains $s$, and every nonempty open set contains $p$. This pattern is typical of small finite topologies, and spotting it makes closure computations quick.

02 Interior and Closure

Main Idea
The interior of $A$ is the largest open set inside $A$. The closure of $A$ is the smallest closed set containing $A$. They are always related by $\operatorname{Int}A\subset A\subset\bar A$.

There are two ways to compute a closure, and you need both. The definition (intersect all closed supersets) is best in finite spaces, where you can list the closed sets. The neighborhood test (Theorem 17.5) is best for proofs and for infinite spaces such as $\mathbb{R}$ or the cofinite topology.

Definition §17

$\operatorname{Int}A$ = the union of all open sets contained in $A$.

$\bar A$ (the closure) = the intersection of all closed sets containing $A$.

$A$ is dense in $X$ if $\bar A=X$.

Reading the definition
The interior is a union of open sets, so it is open by axiom (2). The closure is an intersection of closed sets, so it is closed by Theorem 17.1. $A$ is open exactly when $A=\operatorname{Int}A$, and closed exactly when $A=\bar A$. Note that MT Q2a asks for the definition of closure. Give this intersection definition.
Theorem 17.5 — neighborhood test §17
Let $A\subset X$ and $x\in X$.
  1. $x\in\bar A$ if and only if every open set $U$ containing $x$ intersects $A$.
  2. If the topology is given by a basis, $x\in\bar A$ if and only if every basis element containing $x$ intersects $A$.
Reading the theorem
A point is in the closure exactly when you cannot isolate it from $A$ with an open set. To show $x\notin\bar A$, produce one open set around $x$ that misses $A$. To show $x\in\bar A$, show every open set around $x$ meets $A$.
Worked example — closure and interior on a finite space

Same space: $X=\{p,q,r,s\}$, open sets $\varnothing,\{p\},\{p,q\},\{p,r\},\{p,q,r\},X$. Let $A=\{q\}$.

Closure. The closed sets containing $\{q\}$ are $X$, $\{q,r,s\}$, and $\{q,s\}$. Their intersection is $\{q,s\}$. So $\bar A=\{q,s\}$.

Check with the neighborhood test. $p\notin\bar A$, because $\{p\}$ is open and misses $A$. $r\notin\bar A$, because $\{p,r\}$ is open and misses $A$. $s\in\bar A$, because the only open set containing $s$ is $X$, which meets $A$. Same answer.

Interior. The open sets contained in $\{q\}$: only $\varnothing$, since every nonempty open set contains $p$. So $\operatorname{Int}A=\varnothing$.

Worked example — infinite spaces

Indiscrete topology. If $A\neq\varnothing$, the only closed set containing $A$ is $X$, so $\bar A=X$. Every nonempty set is dense.

$\mathbb{Q}$ in $\mathbb{R}$. Every open interval contains a rational, so by the basis version of Theorem 17.5 every real number lies in $\bar{\mathbb{Q}}$. So $\bar{\mathbb{Q}}=\mathbb{R}$ and $\mathbb{Q}$ is dense. Every open interval also contains an irrational, so $\operatorname{Int}\mathbb{Q}=\varnothing$.

Approach to HW2 Q3 (cofinite topology). First list the closed sets in $\mathcal{T}_f$: by definition they are $X$ and the finite subsets. Then ask, for a given $A$, which closed sets contain it. Whether $A$ is finite or infinite determines the answer, and those are the two cases the problem mentions.

Facts about closure
  • If $A\subset B$, then $\bar A\subset\bar B$. Reason: $\bar B$ is a closed set containing $B\supset A$, and $\bar A$ is the smallest such set.
  • If $C$ is closed and $A\subset C$, then $\bar A\subset C$. This is the definition of "smallest," and it is the most used fact about closure.
These two facts, together with Theorem 17.1, are all that HW2 Q5 needs.

03 Closure Inside a Subspace

Main Idea
If $A\subset Y\subset X$, the closure of $A$ in $Y$ is the closure of $A$ in $X$, cut down to $Y$.

This gives a shortcut for HW2 Q4b: compute the closure in the big space once, then intersect with the subspace. You can also compute directly from the closed sets of the subspace and confirm that the two answers agree.

Theorem 17.4 §17
Let $Y$ be a subspace of $X$ and $A\subset Y$. Let $\bar A$ denote the closure of $A$ in $X$. Then the closure of $A$ in $Y$ equals $\bar A\cap Y$.
Worked example

In $\mathbb{R}$, let $Y=(0,1]$ and $A=(0,\tfrac12)$. The closure of $A$ in $\mathbb{R}$ is $[0,\tfrac12]$. The closure in $Y$ is $[0,\tfrac12]\cap(0,1]=(0,\tfrac12]$. The point $0$ is lost because it is not in $Y$.

There is no corresponding formula for interiors. The interior of $A$ in $Y$ can be larger than $\operatorname{Int}_X(A)\cap Y$. For example, $Y$ is open in itself even when it is not open in $X$. Compute interiors in a subspace directly from $\mathcal{T}_Y$.

04 Limit Points

Main Idea
A limit point of $A$ is a point that every neighborhood brings close to other points of $A$. The closure is $A$ together with its limit points.

A neighborhood of $x$ means, in Munkres, an open set containing $x$. Limit points connect topology back to the sequence-based reasoning from Modern Analysis.

Definition and Theorem 17.6 §17
$x$ is a limit point of $A$ if every neighborhood of $x$ intersects $A$ in some point other than $x$. Writing $A'$ for the set of limit points: $\bar A=A\cup A'$.
Worked example
In $\mathbb{R}$, $A=\{1/n\mid n\in\mathbb{Z}_{\gt0}\}$ has exactly one limit point, $0$. So $\bar A=A\cup\{0\}$, and $A$ is not closed. Each point $1/n$ is isolated: a small enough interval around it contains no other point of $A$. As a subspace, $A$ is therefore discrete but not closed in $\mathbb{R}$. This is the counterexample for MT Q3c.

05 Convergence of Sequences

Main Idea
A sequence converges to $x$ if it eventually enters, and stays in, every neighborhood of $x$. This is the $\varepsilon$–$N$ definition with "within $\varepsilon$" replaced by "inside $U$."

HW3 Q5 asks you to use this definition (Munkres p. 98) in a product space. The behavior of sequences depends heavily on the topology. With very few open sets, sequences converge easily. With very many, they converge rarely.

Definition §17, p. 98
A sequence $x_1,x_2,\dots$ in $X$ converges to $x\in X$ if for each neighborhood $U$ of $x$ there is a positive integer $N$ such that $x_n\in U$ for all $n\ge N$.
Worked example — two extremes

Discrete space. $\{x\}$ is a neighborhood of $x$. So $x_n\to x$ forces $x_n\in\{x\}$, that is, $x_n=x$, for all $n\ge N$. In a discrete space a sequence converges exactly when it is eventually constant. This applies to each factor $\{0,1\}$ in HW3 Q5.

Indiscrete space. The only neighborhood of $x$ is $X$, which contains every $x_n$. So every sequence converges to every point. Limits are not unique here, and the Hausdorff condition is what prevents this.

06 Hausdorff Spaces

Main Idea
In a Hausdorff space, any two distinct points can be put in disjoint open sets. This is the condition that makes limits unique and makes one-point sets closed. Every metric space is Hausdorff.

The Hausdorff condition appears in HW2 Q6, HW3 Q3, HW3 Q4b, and MT Q3a. In proofs it is used in one particular way: assume two things differ, then use disjoint open sets around them to reach a contradiction or to build an open set. The worked proof below shows this technique.

Definition §17
$X$ is Hausdorff if for each pair $x_1\neq x_2$ in $X$ there exist neighborhoods $U_1\ni x_1$ and $U_2\ni x_2$ with $U_1\cap U_2=\varnothing$.
Theorems 17.8 and 17.10 §17
In a Hausdorff space, every finite point set is closed (17.8), and a sequence converges to at most one point (17.10).
Worked proof — limits are unique in a Hausdorff space

Suppose $x_n\to x$ and $x_n\to y$ with $x\neq y$. By the Hausdorff property choose disjoint open $U\ni x$ and $V\ni y$. By convergence to $x$, there is $N_1$ with $x_n\in U$ for $n\ge N_1$. By convergence to $y$, there is $N_2$ with $x_n\in V$ for $n\ge N_2$. For $n=\max(N_1,N_2)$, $x_n\in U\cap V=\varnothing$, a contradiction.

The technique. To prove two things are equal in a Hausdorff space, assume they differ, separate them by disjoint open sets, and use continuity or convergence to force a point into both. HW3 Q3 is solved the same way.

Worked example — spaces that are not Hausdorff

Indiscrete with at least 2 points: the only nonempty open set is $X$, so two points cannot be separated.

Finite complement topology on an infinite $X$: two nonempty open sets $U,V$ have finite complements, so $U\cap V$ has complement $(X\setminus U)\cup(X\setminus V)$, which is finite. Since $X$ is infinite, $U\cap V$ is nonempty. So no two nonempty open sets are disjoint.

Subspaces of $\mathbb{R}$ are Hausdorff (MT Q3a): for $x\neq y$ in $A$, take $r=|x-y|/2$. The intervals $(x-r,x+r)$ and $(y-r,y+r)$ are disjoint, and their traces on $A$ are disjoint open sets of $A$.

Proof pattern for HW2 Q6
Products: two distinct points $(x_1,y_1)\neq(x_2,y_2)$ differ in at least one coordinate. Separate in that coordinate, then take the preimage under the corresponding projection, or form the product with the whole other factor. Subspaces: separate in $X$, then intersect with $Y$, exactly as in the $\mathbb{R}$ example above.

Product Topologies

The topology on $X\times Y$, projections, arbitrary products $\prod X_j$, the product versus box topology, and sequences in products.

01 The Product Topology on $X\times Y$

Main Idea
The open sets of $X\times Y$ are built from "open rectangles" $U\times V$, where $U$ is open in $X$ and $V$ is open in $Y$. A general open set is a union of such rectangles. It need not be a rectangle itself.

In $\mathbb{R}^2$ this gives the usual topology: the open rectangles $(a,b)\times(c,d)$ form a basis. The definition works for any two spaces, and the problems use it with discrete, indiscrete, and Hausdorff factors.

Definition §15
The product topology on $X\times Y$ is the topology with basis $$\mathcal{B}=\{\,U\times V\mid U\text{ open in }X,\ V\text{ open in }Y\,\}.$$
Why this is a basis
Condition (1): $X\times Y$ is itself a basis element. Condition (2): $(U_1\times V_1)\cap(U_2\times V_2)=(U_1\cap U_2)\times(V_1\cap V_2)$, which is again a basis element. This identity, "intersection of rectangles is a rectangle," is used constantly.
Theorem 15.1 §15
If $\mathcal{B}$ is a basis for $X$ and $\mathcal{C}$ is a basis for $Y$, then $\{B\times C\mid B\in\mathcal{B},C\in\mathcal{C}\}$ is a basis for the product topology on $X\times Y$.
Worked example — a small finite product

Let $S=\{0,1\}$ with topology $\{\varnothing,\{1\},S\}$ (the Sierpiński space). The basis for $S\times S$ consists of products of the open sets $\varnothing,\{1\},S$:

$\{1\}\times\{1\}=\{(1,1)\}$, $\ \{1\}\times S=\{(1,0),(1,1)\}$, $\ S\times\{1\}=\{(0,1),(1,1)\}$, $\ S\times S$, together with products involving $\varnothing$, which are all $\varnothing$.

The union $\{(1,0),(1,1)\}\cup\{(0,1),(1,1)\}=\{(1,0),(0,1),(1,1)\}$ is open but not a rectangle. Is $\{(0,0)\}$ open? Every basis element containing $(0,0)$ is $S\times S$, so no.

For HW2 Q1, apply the same method: list the basis elements, then ask which one-point sets they produce (discrete case) or which sets they can be at all (indiscrete case).

02 Projections

Main Idea
The projection $\pi_1:X\times Y\to X$, $(x,y)\mapsto x$, forgets the second coordinate. Projections are continuous, and they also send open sets to open sets. They do not generally send closed sets to closed sets.

Continuity of $\pi_1$ is a preimage statement and is immediate. That projections carry open sets to open sets (they are open maps) is an image statement, which is HW2 Q2. Since an arbitrary open $W$ is a union of rectangles, and images preserve unions, the work reduces to computing the image of one rectangle.

Preimages under projections §15
$\pi_1^{-1}(U)=U\times Y$ and $\pi_2^{-1}(V)=X\times V$. Hence $\pi_1,\pi_2$ are continuous, and $U\times V=\pi_1^{-1}(U)\cap\pi_2^{-1}(V)$.
Worked example — image of a rectangle

$\pi_1(U\times V)=U$ if $V\neq\varnothing$: every $x\in U$ is the image of $(x,v)$ for any chosen $v\in V$. If $V=\varnothing$, then $U\times V=\varnothing$ and the image is $\varnothing$. Both are open in $X$. Handle the empty case explicitly in a proof.

Worked example — projections are not closed maps
The hyperbola $H=\{(x,y)\in\mathbb{R}^2\mid xy=1\}$ is closed in $\mathbb{R}^2$, because it is the preimage of the closed set $\{1\}$ under the continuous map $(x,y)\mapsto xy$. But $\pi_1(H)=\mathbb{R}\setminus\{0\}$ is not closed. So "open map" really is special to open sets.

03 Arbitrary Products: Product versus Box Topology

Main Idea
For a product of infinitely many spaces there are two natural topologies. The box topology allows open sets restricted in every coordinate at once. The product topology allows restrictions in only finitely many coordinates, leaving all other coordinates completely free. The product topology is the standard one, and it is what HW3 Q5–Q6 and MT Q5 use.

An element of $\prod_{j\in J}X_j$ is a family $x=(x_j)_{j\in J}$ with $x_j\in X_j$ for each $j$. When $J$ is infinite, a basic open set in the product topology can only "see" finitely many coordinates. This is the fact behind HW3 Q6: a one-point set constrains every coordinate, so when $J$ is infinite (and the factors have at least two points) it cannot be open.

Definition — product topology §19
The product topology on $\prod_{j\in J}X_j$ has basis all sets $\prod_{j\in J}U_j$ such that each $U_j$ is open in $X_j$ and $U_j=X_j$ for all but finitely many $j$. Equivalently, the basis consists of finite intersections $\pi_{j_1}^{-1}(U_1)\cap\dots\cap\pi_{j_n}^{-1}(U_n)$.

The box topology has basis all $\prod U_j$ with each $U_j$ open, with no finiteness condition. For finite $J$ the two agree (Theorem 19.1).
Reading the definition
Read $\pi_{j}^{-1}(U)$ as "the set of points whose $j$-th coordinate lies in $U$." A basic open set imposes conditions on finitely many coordinates $j_1,\dots,j_n$ and leaves every other coordinate unconstrained. The product topology is coarser than the box topology. It is the coarsest topology making every projection $\pi_j$ continuous.
Worked example — an open set in the box topology that is not open in the product topology

In $\mathbb{R}^\omega=\prod_{n\in\mathbb{Z}_{\gt0}}\mathbb{R}$, let $W=\prod_n(-1,1)$. It is a basis element of the box topology. In the product topology, any basic open set containing $0=(0,0,\dots)$ leaves some coordinate $k$ free, so it contains a point with $k$-th coordinate $5$, which is not in $W$. So $W$ is not open in the product topology.

The same argument shows: if $J$ is infinite and every $X_j$ has at least two points, then no one-point set is open in the product topology. Any basic open set containing $x$ leaves a coordinate $k$ free, and you can change $x_k$ to a different value of $X_k$ while staying in that set.

Theorem 19.6 — maps into products §19
Let $f:A\to\prod X_j$ be given by $f(a)=(f_j(a))_{j\in J}$, with the product topology on the target. Then $f$ is continuous if and only if each $f_j=\pi_j\circ f$ is continuous. This fails for the box topology.
Theorem 19.5 — closures in products §19
For $A_j\subset X_j$, in either the product or the box topology: $\overline{\prod A_j}=\prod\bar A_j$.
Two routes for MT Q5
Route 1 (complement). Use the identity from the Set Toolkit: $\prod X_j\setminus\prod A_j=\bigcup_k\pi_k^{-1}(X_k\setminus A_k)$. Each piece is a preimage of an open set under a continuous projection, so the union is open. Route 2 (closure). Apply Theorem 19.5 with $\bar A_j=A_j$. On a closed-book exam, Route 1 is safer because it does not depend on citing a theorem correctly.

04 Sequences in a Product

Main Idea
In the product topology, a sequence converges exactly when each coordinate converges. Because a basic neighborhood constrains only finitely many coordinates, you only ever need to wait for finitely many coordinates to settle down, and the maximum of finitely many $N$'s is finite.

This is Munkres Exercise 19.6. Since it is an exercise rather than a theorem in the text, prove the direction you need directly in HW3 Q5 rather than citing it. The proof pattern is below.

Worked proof — coordinatewise convergence implies convergence

Suppose $x^{(n)}\in\prod X_j$ and $x^{(n)}_j\to x_j$ in $X_j$ for every $j$. Let $U$ be any neighborhood of $x=(x_j)$.

Step 1. Shrink to a basic open set: there is a basis element $B=\pi_{j_1}^{-1}(U_1)\cap\dots\cap\pi_{j_k}^{-1}(U_k)$ with $x\in B\subset U$. Here each $U_i$ is open in $X_{j_i}$ and contains $x_{j_i}$.

Step 2. For each $i=1,\dots,k$, coordinate convergence gives $N_i$ with $x^{(n)}_{j_i}\in U_i$ for all $n\ge N_i$.

Step 3. Let $N=\max(N_1,\dots,N_k)$. For $n\ge N$, every one of the $k$ conditions holds, so $x^{(n)}\in B\subset U$.

Step 3 is where finiteness matters. In the box topology there could be infinitely many $N_i$ with no finite maximum.

Continuous Functions

Continuity defined by open sets, checking it on a basis, the standard rules, homeomorphisms and embeddings, and the set where two continuous maps agree.

01 Definition

Main Idea
Recall from Modern Analysis (Rudin 4.8): a map between metric spaces is continuous exactly when the preimage of every open set is open. Topology takes that characterization as the definition. With no distance available, it is the only way to say "nearby points go to nearby points."

Every continuity proof in this course has the same opening line: "Let $V$ be open in $Y$. We show $f^{-1}(V)$ is open in $X$." Every proof of discontinuity names one open $V$ whose preimage is not open. Whether a given $f$ is continuous depends on both topologies. The same formula can be continuous for one choice of topologies and not for another, which is the point of HW3 Q2 and MT Q4.

Definition §18
$f:X\to Y$ is continuous if for every open $V\subset Y$, the preimage $f^{-1}(V)$ is open in $X$.
Theorem 18.1 — equivalent conditions §18
For $f:X\to Y$, the following are equivalent:
  1. $f$ is continuous.
  2. For every $A\subset X$: $f(\bar A)\subset\overline{f(A)}$.
  3. For every closed $B\subset Y$, $f^{-1}(B)$ is closed in $X$.
  4. For each $x\in X$ and each neighborhood $V$ of $f(x)$, there is a neighborhood $U$ of $x$ with $f(U)\subset V$.
Reading the conditions
(3) is (1) with complements taken, using $f^{-1}(Y\setminus B)=X\setminus f^{-1}(B)$. It is the more convenient form when the target's closed sets are easier to describe than its open sets, as in the cofinite topology, where the closed sets are just the finite sets and $Y$. (2) says continuous maps send points of the closure into the closure of the image, so limits are preserved. (4) is the $\varepsilon$–$\delta$ definition in topological language.
Worked example — the same formula, different topologies

Let $f:\mathbb{R}\to\mathbb{R}$, $f(x)=x$.

  • From $\mathbb{R}$ discrete to $\mathbb{R}$ standard: continuous, since every preimage is open in the discrete topology.
  • From $\mathbb{R}$ standard to $\mathbb{R}$ discrete: not continuous. $V=\{0\}$ is open in the target, but $f^{-1}(V)=\{0\}$ is not open in the standard topology.
  • From $\mathbb{R}$ standard to $\mathbb{R}_f$ (finite complement topology): continuous. A nonempty open $V$ has the form $\mathbb{R}\setminus F$ with $F$ finite, and $f^{-1}(V)=\mathbb{R}\setminus F$, which is open in the standard topology because finite sets are closed there.

The last case is a special case of MT Q4b, where $f$ is any injective map. Injectivity guarantees that preimages of finite sets are still finite (Set Toolkit, Section 02).

Worked example — maps out of discrete or into indiscrete spaces

If $X$ is discrete, every function $f:X\to Y$ is continuous, because every subset of $X$ is open. A finite subspace of $\mathbb{R}$ is discrete, since each point can be isolated by a small interval. So every function from a finite $A\subset\mathbb{R}$ to $\mathbb{R}$ is continuous. This is MT Q3b.

If $Y$ is indiscrete, every function $f:X\to Y$ is continuous, because the only preimages to check are $f^{-1}(\varnothing)=\varnothing$ and $f^{-1}(Y)=X$. This supplies counterexamples whenever a theorem needs $Y$ to be Hausdorff, as in HW3 Q3b.

Worked example — continuity on a finite space

Let $X=\{a,b,c\}$ with $\mathcal{T}_X=\{\varnothing,\{a\},\{a,b\},X\}$, and $S=\{0,1\}$ with $\mathcal{T}_S=\{\varnothing,\{1\},S\}$. Define $f(a)=1,f(b)=1,f(c)=0$. The only open set to check is $\{1\}$: $f^{-1}(\{1\})=\{a,b\}$, which is open. So $f$ is continuous. If instead $g(a)=1,g(b)=0,g(c)=1$, then $g^{-1}(\{1\})=\{a,c\}$, which is not in $\mathcal{T}_X$, so $g$ is not continuous.

02 Checking Continuity on a Basis

Main Idea
You do not have to check every open set of the target. It is enough to check that the preimage of every basis element is open. Every open set is a union of basis elements, and preimages preserve unions.

This turns continuity problems into product spaces (HW3 Q1) into a computation with rectangles. The argument is short and should be written out in full the first time you use it.

Lemma — basis check §18
If $\mathcal{B}$ is a basis for the topology of $Y$ and $f^{-1}(B)$ is open for every $B\in\mathcal{B}$, then $f$ is continuous.

Proof. Let $V$ be open in $Y$. By Lemma 13.1, $V=\bigcup_\alpha B_\alpha$ for some $B_\alpha\in\mathcal{B}$. Then $f^{-1}(V)=\bigcup_\alpha f^{-1}(B_\alpha)$ is a union of open sets, hence open.
Worked example — the swap map

Claim. $s:X\times Y\to Y\times X$, $s(x,y)=(y,x)$, is continuous (product topologies on both sides).

Proof. A basis for $Y\times X$ is $\{V\times U\mid V\text{ open in }Y,\ U\text{ open in }X\}$. Compute the preimage of a basis element: $$s^{-1}(V\times U)=\{(x,y)\mid (y,x)\in V\times U\}=\{(x,y)\mid x\in U,\ y\in V\}=U\times V,$$ which is a basis element of $X\times Y$, hence open. By the basis check, $s$ is continuous.

Read-through. The middle equality just unpacks membership: $(y,x)\in V\times U$ means $y\in V$ and $x\in U$. HW3 Q1 has the same structure. Compute $h^{-1}(U\times V)$ for a basic open set of $B\times D$, unpack the membership condition coordinate by coordinate, and recognize the result as a product of preimages.

Theorem 18.2 — rules for continuous maps §18
  • Constant maps are continuous.
  • Inclusion of a subspace $A\hookrightarrow X$ is continuous.
  • Compositions of continuous maps are continuous.
  • Restricting the domain: if $f$ is continuous, so is $f|_A$.
  • Restricting or expanding the range: if $f:X\to Y$ is continuous and $f(X)\subset Z\subset Y$, then $f:X\to Z$ is continuous (with the subspace topology on $Z$), and the same holds for a larger space containing $Y$.

03 Homeomorphisms and Embeddings

Main Idea
A homeomorphism is a bijection that matches up the open sets on both sides exactly. Two homeomorphic spaces are the same space as far as topology can tell. An embedding is a map that is a homeomorphism onto its image, so it places a faithful copy of $X$ inside $Y$.

A continuous bijection need not be a homeomorphism: its inverse can fail to be continuous. This is the most common trap in this section, and HW3 Q2b and Q4b are both built around it.

Definitions §18

$f:X\to Y$ is a homeomorphism if $f$ is a bijection and both $f$ and $f^{-1}$ are continuous. Equivalently: $f$ is a bijection, and $U$ is open in $X$ if and only if $f(U)$ is open in $Y$.

$f:X\to Y$ is an embedding (imbedding, in Munkres) if $f$ is injective and continuous, and the map $f':X\to f(X)$ obtained by restricting the range is a homeomorphism, where $f(X)$ has the subspace topology from $Y$.

Worked example — continuous bijection, not a homeomorphism

The identity $\mathrm{id}:(\mathbb{R},\text{discrete})\to(\mathbb{R},\text{standard})$ is a continuous bijection, but its inverse $(\mathbb{R},\text{standard})\to(\mathbb{R},\text{discrete})$ is not continuous, because $\{0\}$ pulls back to a non-open set. In terms of the definition, $\{0\}$ is open in the domain but its image $\{0\}$ is not open in the target.

This is the identity-map situation of HW3 Q2. There, both directions of the identity reduce to inclusions between the two topologies.

Worked example — injective and continuous, but not an embedding

Let $f:[0,1)\to\mathbb{R}^2$, $f(t)=(\cos2\pi t,\sin2\pi t)$. It is continuous and injective, with image the unit circle $S^1$. But it is not an embedding. The set $[0,\tfrac12)$ is open in $[0,1)$, while its image, an arc that includes the endpoint $(1,0)$, is not open in $S^1$: points of $S^1$ just below $(1,0)$ are close to $(1,0)$ but not in the arc.

How to prove that something is an embedding (HW3 Q4b). Show that $f$ is injective and continuous, and that the inverse $f(X)\to X$ is continuous. A convenient way to get the inverse is to find a continuous map defined on all of $Y$ whose restriction to $f(X)$ is the inverse. Restricting a continuous map to a subspace keeps it continuous (Theorem 18.2).

04 The Set Where Two Maps Agree

Main Idea
For two continuous real-valued functions, the set where they agree is closed, because it is the zero set of the continuous function $f-g$. For maps into a general space there is no subtraction, but the Hausdorff property can do the same job. This is the idea behind HW3 Q3 and Q4b.

This section works the real-valued case in full and then sets up the general question. The general proof is HW3 Q3 itself, and the hints in the Problems tab guide you through it.

Worked example — real-valued maps

Claim. If $f,g:X\to\mathbb{R}$ are continuous, then $E=\{x\in X\mid f(x)=g(x)\}$ is closed in $X$.

Proof. The function $f-g$ is continuous (a difference of continuous real functions), and $E=(f-g)^{-1}(\{0\})$. The set $\{0\}$ is closed in $\mathbb{R}$, so $E$ is closed by Theorem 18.1(3).

Consequence. If $f$ and $g$ agree on a dense set $A$, then $A\subset E$ with $E$ closed, so $X=\bar A\subset E$, and $f=g$ everywhere. Example: a continuous $f:\mathbb{R}\to\mathbb{R}$ that vanishes on $\mathbb{Q}$ vanishes everywhere.

The general question
For $f,g:X\to Y$ with $Y$ only a topological space, $f-g$ has no meaning. Show instead that the complement $\{x\mid f(x)\neq g(x)\}$ is open. Take a point $x$ where $f(x)\neq g(x)$. These are two distinct points of $Y$. What does the Hausdorff property give you, and how can continuity of $f$ and $g$ turn that into an open set around $x$? The worked proof that limits are unique (Closure tab, Section 06) uses the same technique.

The Metric Topology

Metrics, $\varepsilon$-balls, and the triangle-inequality argument that shows a set is open or closed.

01 Metrics and the Metric Topology

Main Idea
A metric is a distance function. Every metric produces a topology whose basis is the open balls. This places Modern Analysis inside topology: every metric space from Rudin is a topological space, and the definitions agree.

MT Q6 asks for the metric axioms word for word and then for one triangle-inequality argument. The argument below for "an open ball is open" is the model. The midterm's closed-ball problem is the same argument applied to the complement.

Definition — metric §20
A metric on $X$ is a function $d:X\times X\to\mathbb{R}$ such that for all $x,y,z\in X$:
  1. $d(x,y)\ge0$, with equality if and only if $x=y$. (positivity)
  2. $d(x,y)=d(y,x)$. (symmetry)
  3. $d(x,y)+d(y,z)\ge d(x,z)$. (triangle inequality)
The $\varepsilon$-ball centered at $x$ is $B_d(x,\varepsilon)=\{y\mid d(x,y)\lt\varepsilon\}$. The metric topology is the topology with basis all $\varepsilon$-balls, for all $x\in X$ and $\varepsilon\gt0$.
Open sets in the metric topology §20
$U$ is open if and only if for each $y\in U$ there is $\delta\gt0$ with $B_d(y,\delta)\subset U$.
Worked proof — an open ball is open

Claim. $B=B_d(x,\varepsilon)$ is open.

Proof. Let $y\in B$, so $d(x,y)\lt\varepsilon$. Set $\delta=\varepsilon-d(x,y)\gt0$. If $z\in B_d(y,\delta)$, then $$d(x,z)\le d(x,y)+d(y,z)\lt d(x,y)+\delta=\varepsilon,$$ so $z\in B$. Hence $B_d(y,\delta)\subset B$.

Read-through. $\delta$ is the room left between $y$ and the edge of the ball. The triangle inequality says any point within $\delta$ of $y$ is within $d(x,y)+\delta=\varepsilon$ of the center.

For the closed-ball problem (MT Q6b)
To show $A=\{y\mid d(x,y)\le1\}$ is closed, show that its complement $\{z\mid d(x,z)\gt1\}$ is open. For such a $z$, the room is now $d(x,z)-1\gt0$. Use the triangle inequality in the form $d(x,z)\le d(x,w)+d(w,z)$ to show that every $w$ close to $z$ also has $d(x,w)\gt1$.
Worked example — the discrete metric
On any set, $d(x,y)=1$ for $x\neq y$ and $d(x,x)=0$ is a metric. The ball $B_d(x,\tfrac12)=\{x\}$, so every one-point set is open and the metric topology is discrete. Note that $\{y\mid d(x,y)\le1\}=X$, while $\{y\mid d(x,y)\lt1\}=\{x\}$. In this space the closed ball is not the closure of the open ball.

HW1 Q4If $Y$ is a subspace of $X$ and $A\subset Y$, prove the topology $A$ inherits from $Y$ equals the topology $A$ inherits from $X$.
Read: Subspace topology · Two inclusions
Solution

Let $\mathcal{T}$ be the topology of $X$. Then $\mathcal{T}_Y=\{Y\cap U\mid U\in\mathcal{T}\}$. The topology $A$ inherits from $Y$ is $(\mathcal{T}_Y)_A=\{A\cap V\mid V\in\mathcal{T}_Y\}$, and the one it inherits from $X$ is $\mathcal{T}_A=\{A\cap U\mid U\in\mathcal{T}\}$.

Key identity: since $A\subset Y$, $A\cap Y=A$, so $A\cap(Y\cap U)=(A\cap Y)\cap U=A\cap U$.

($\subset$) Let $W\in(\mathcal{T}_Y)_A$. Then $W=A\cap V$ with $V=Y\cap U$, $U\in\mathcal{T}$. So $W=A\cap(Y\cap U)=A\cap U\in\mathcal{T}_A$.

($\supset$) Let $W\in\mathcal{T}_A$, so $W=A\cap U$ with $U\in\mathcal{T}$. Put $V=Y\cap U\in\mathcal{T}_Y$. Then $A\cap V=A\cap U=W$, so $W\in(\mathcal{T}_Y)_A$.

HW2 Q1If $X$ and $Y$ are discrete, prove $X\times Y$ is discrete. Then prove the analogous statement for indiscrete.
Read: Product basis
Solution

Discrete. The product topology is contained in $\mathcal{P}(X\times Y)$, so it suffices to show every subset is open. For $(x,y)\in X\times Y$, $\{x\}$ and $\{y\}$ are open, so $\{(x,y)\}=\{x\}\times\{y\}$ is a basis element and hence open. Any $W\subset X\times Y$ equals $\bigcup_{w\in W}\{w\}$, a union of open sets, so it is open.

Indiscrete. The basis elements are $U\times V$ with $U\in\{\varnothing,X\}$ and $V\in\{\varnothing,Y\}$. Each is either $\varnothing$ (if a factor is empty) or $X\times Y$. By Lemma 13.1 the open sets are the unions of these, which are again only $\varnothing$ and $X\times Y$. So the product topology is $\{\varnothing,X\times Y\}$.

HW2 Q2Prove that if $W\subset X\times Y$ is open, then $\pi_1(W)$ is open in $X$.
Read: Projections · Images preserve unions
Solution

By Lemma 13.1, $W=\bigcup_{\alpha}(U_\alpha\times V_\alpha)$ with each $U_\alpha$ open in $X$ and $V_\alpha$ open in $Y$. Images preserve unions: $x\in\pi_1(\bigcup S_\alpha)$ iff $x=\pi_1(w)$ for some $w$ in some $S_\alpha$, iff $x\in\bigcup\pi_1(S_\alpha)$. So $\pi_1(W)=\bigcup_\alpha\pi_1(U_\alpha\times V_\alpha)$.

If $V_\alpha\neq\varnothing$, then $\pi_1(U_\alpha\times V_\alpha)=U_\alpha$: "$\subset$" is clear, and for $x\in U_\alpha$ pick $v\in V_\alpha$, so $x=\pi_1(x,v)$. If $V_\alpha=\varnothing$, the image is $\varnothing$. In both cases the image is open, so $\pi_1(W)$ is a union of open sets and is open.

HW2 Q3$X$ infinite with the finite complement topology. Describe $\bar A$ for $A\subset X$. Justify. (Two cases.)
Read: Closure
Solution

$C$ is closed iff $X\setminus C$ is open iff $X\setminus C=\varnothing$ or $X\setminus(X\setminus C)=C$ is finite. So the closed sets are $X$ and the finite subsets.

$A$ finite: $A$ is closed, so $\bar A=A$.

$A$ infinite: a closed set containing $A$ is infinite, so it cannot be finite, and the only remaining closed set is $X$. Hence $\bar A=X$.

HW2 Q5(a) Prove $\bigcup_j\bar A_j\subset\overline{\bigcup_jA_j}$. (b) Prove equality when $J$ is finite. (c) Show equality can fail in general.
Read: Facts about closure · Finite vs arbitrary
Solution

(a) Let $C=\overline{\bigcup_jA_j}$, a closed set. For each $k$, $A_k\subset\bigcup_jA_j\subset C$, so $\bar A_k\subset C$, because $\bar A_k$ is the smallest closed set containing $A_k$. Taking the union over $k$ gives $\bigcup_k\bar A_k\subset C$.

(b) If $J$ is finite, $\bigcup_j\bar A_j$ is a finite union of closed sets, so it is closed (Theorem 17.1), and it contains $\bigcup_jA_j$. Hence $\overline{\bigcup_jA_j}\subset\bigcup_j\bar A_j$. Combined with (a), the two sets are equal.

(c) In $\mathbb{R}$, let $A_n=\{1/n\}$ for $n\in\mathbb{Z}_{\gt0}$. Each $A_n$ is closed, so $\bigcup\bar A_n=\{1/n\mid n\ge1\}$, which does not contain $0$. But $0\in\overline{\bigcup A_n}$: every interval around $0$ contains some $1/n$. So the inclusion is strict.
